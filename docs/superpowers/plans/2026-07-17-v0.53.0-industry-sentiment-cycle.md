# v0.53.0 Industry Sentiment Cycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic, confidence-aware industry sentiment score, retained history, experimental sentiment projection, and peak/trough turning-risk windows to the existing Taiwan market-intelligence pipeline.

**Architecture:** Keep network and filesystem work in the existing batch orchestration layer, add focused pure modules for the lexicon, scoring, forecasting, and validation, and persist one CSV snapshot per industry per market date. The market-intelligence builder performs a two-pass calculation: score every industry first, assign deterministic ranks second, then finalize cycle, forecast, and turning risk from history without future data.

**Tech Stack:** Python 3.10+ standard library, existing `argparse` CLI, CSV/JSON/HTML batch artifacts, `unittest`, official TWSE/TPEx HTTP endpoints, no runtime third-party dependencies.

**Approved Design:** `docs/superpowers/specs/2026-07-17-v0.53.0-industry-sentiment-cycle-design.md`

## Global Constraints

- Methodology version is exactly `industry-sentiment-v1`.
- Composite configured weights are news `0.40`, price `0.30`, and institutional flow `0.30`.
- Every component and composite score is clamped to `[-100, 100]`; displayed values are rounded to one decimal place only at the output boundary.
- A numeric composite requires at least two fresh usable components. With exactly two, configured weights are renormalized, status is `partial`, and confidence cannot be `high`.
- News uses title weight `0.65`, summary weight `0.35`, negation within three deterministic tokens, maximum intensity multiplier `2.0`, half-life `3` days for 5D and `7` days for 20D, and a `40%` per-source cap.
- Source weight clipped by the `40%` cap remains neutral unallocated coverage; it is never redistributed to the same one or two sources.
- Price uses return scales `8%` for 5D and `15%` for 20D, with return/breadth/volume weights `0.60/0.25/0.15`.
- Flow uses net institutional shares divided by joined traded shares, with ratio/persistence weights `0.75/0.25` and ratio scale `0.05`.
- Flow requires at least `3` valid sessions in the latest 5 expected sessions and `10` valid sessions in the latest 20; a valid session covers at least `60%` of the industry's price-covered mapped stocks.
- Temperature thresholds are warming at `change >= 10`, cooling at `change <= -10`, and stable otherwise.
- Labels are `extremely_optimistic >= 60`, `optimistic >= 20`, `neutral (-20, 20)`, `pessimistic <= -20`, and `extremely_pessimistic <= -60`.
- Forecast is suppressed below `20` valid snapshots; turning risk and a turning window are suppressed below `60` valid snapshots.
- Turning values are named `risk`, not `probability`, until every promotion gate passes.
- Runtime features may read only snapshots with `as_of_date <= current as_of_date`; backtest-only future labels must remain in the validation module.
- Missing, stale, invalid, or source-error inputs remain explicit and are never converted to zero or neutral evidence.
- The output remains descriptive research support and must not emit buy/sell, target-price, allocation, exact turning-date, or guaranteed-return claims.
- A future LLM reviewer may add a separate `llm_review` payload but cannot overwrite `deterministic_score` in v1.

```python
def fetch_fund_flow_history(
    *,
    as_of: date | datetime | str | None = None,
    session_count: int = 20,
    max_calendar_days: int = 45,
    markets: tuple[str, ...] = ("TWSE", "TPEX"),
) -> tuple[list[dict[str, Any]], list[str]]:
    target = _as_of_datetime(as_of).date()
    selected = tuple(dict.fromkeys(markets))
    sessions = {market: set() for market in selected}
    rows: list[dict[str, Any]] = []
    errors: list[str] = []
    fetchers = {
        "TWSE": fetch_twse_fund_flow_for_date,
        "TPEX": fetch_tpex_fund_flow_for_date,
    }
    for offset in range(max_calendar_days):
        requested = target - timedelta(days=offset)
        if requested.weekday() >= 5:
            continue
        for market in selected:
            if len(sessions[market]) >= session_count:
                continue
            try:
                daily_rows = fetchers[market](requested)
            except (OSError, ValueError) as exc:
                errors.append(f"{market} fund flow {requested.isoformat()}: {exc}")
                continue
            if daily_rows:
                sessions[market].add(requested.isoformat())
                rows.extend(daily_rows)
        if all(len(values) >= session_count for values in sessions.values()):
            break
    deduped = {
        (str(row["date"]), str(row["stock_id"]), str(row["source"])): row
        for row in rows
    }
    ordered = [deduped[key] for key in sorted(deduped)]
    for market, values in sessions.items():
        if len(values) < session_count:
            errors.append(f"{market} fund flow: collected {len(values)} of {session_count} sessions")
    return ordered, errors
```

- [ ] **Step 4: Implement deterministic tokenization and text scoring**

Normalize with Unicode NFKC, lowercase Latin text, and collapsed whitespace. Longest-match the union of every lexicon phrase; unmatched characters are individual tokens. For each sentiment token, search the preceding three tokens for the closest negation and intensity tokens. Multiply once by the largest intensity and flip sign once for negation. Use this output scale:

```python
def score_news_text(text: str) -> float:
    tokens = tokenize_sentiment_text(text)
    total = 0.0
    sentiments = {**POSITIVE_TERMS, **NEGATIVE_TERMS}
    for index, token in enumerate(tokens):
        if token not in sentiments:
            continue
        prefix = tokens[max(0, index - 3):index]
        multiplier = max(
            [INTENSIFIERS[value] for value in prefix if value in INTENSIFIERS],
            default=1.0,
        )
        multiplier = min(multiplier, 2.0)
        sign = -1.0 if any(value in NEGATIONS for value in prefix) else 1.0
        total += sentiments[token] * multiplier * sign
    return 100.0 * _clamp(total / 4.0, -1.0, 1.0)
```

Define `_clamp` in this module and retain full precision internally.

- [ ] **Step 5: Implement article and window scoring with neutral unallocated source weight**

For each deduplicated article, calculate `article_score = 0.65 * title_score + 0.35 * summary_score`. For a requested window, ignore future and older rows, calculate raw exponential weight `0.5 ** (age_days / half_life)`, and group raw weights by source. Cap each source's usable raw weight at `0.40 * total_raw_weight`; scale every article in that source proportionally to the usable source weight. Divide the weighted score by `total_raw_weight`, not by usable weight, leaving clipped weight neutral.

```python
def _eligible_news(
    rows: Sequence[Mapping[str, Any]],
    *,
    as_of: datetime,
    window_days: int,
    half_life_days: float,
) -> list[dict[str, Any]]:
    selected: list[dict[str, Any]] = []
    for row in rows:
        published = datetime.fromisoformat(str(row["published_at"]).replace("Z", "+00:00"))
        if published.tzinfo is None:
            published = published.replace(tzinfo=as_of.tzinfo)
        age_days = (as_of - published).total_seconds() / 86400.0
        if age_days < 0 or age_days > window_days:
            continue
        item = dict(row)
        item["raw_weight"] = 0.5 ** (age_days / half_life_days)
        selected.append(item)
    return selected


def _score_news_window(
    rows: list[dict[str, Any]],
    *,
    as_of: datetime,
    window_days: int,
    half_life_days: float,
) -> tuple[float | None, list[dict[str, Any]], float]:
    eligible = _eligible_news(
        rows,
        as_of=as_of,
        window_days=window_days,
        half_life_days=half_life_days,
    )
    if not eligible:
        return None, [], 0.0
    total_raw = sum(float(row["raw_weight"]) for row in eligible)
    by_source: dict[str, float] = defaultdict(float)
    for row in eligible:
```

```python
def _weighted_slope(values: list[float], half_life: float = 3.0) -> float:
    x_values = [float(index) for index in range(len(values))]
    weights = [0.5 ** ((len(values) - 1 - index) / half_life) for index in range(len(values))]
    weight_sum = sum(weights)

        for weight, x_value, y_value in zip(weights, x_values, values)
    )
    return numerator / denominator
```
